# Cascade2dx
Cocos2d-x v2 fork, oriented for modern platforms, C++11 and higher

## Main features:
- Fast compilation
- Low dependency
- High compability
- Open and easy to modify

## Main changes:
- C++11 and higher support
- (in plans) New perspective camera
- (in plans) New touch handler
- Python 3.x project creator


# Who is Cascade2dx for

| Game creator who need crossplaform engine | Who loves C++ and raw pointers :) | Developers who need to update their old games written in Cocos2d-x v2 |
|-----------|-----------|-----------|
| Those requiring a lightweight, stable, proven solution compatible with older hardware. | Who looking for a free solution. | Those who prefer a code-only engine, without a graphical user interface. |
